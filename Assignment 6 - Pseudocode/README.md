# Overview
This assignment involves writing pseudocode that describes how a digital triage system processes patient vital signs and assigns a risk category. The system uses the vital signs available in the emergency triage dataset: GCS, SBP, DBP, MAP, pulse, temperature, respiratory rate (RR), and FiO₂. The output is a triage priority from 1 (Immediate) to 5 (Non‑urgent) based on physiological thresholds and presenting complaint keywords.
