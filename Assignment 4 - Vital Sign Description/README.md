# Assignment 4 – Vital Sign Description (Systolic Blood Pressure)

## Overview
This assignment describes systolic blood pressure (SBP), its clinical ranges, and its importance in triage.

## Selected Vital Sign
**Systolic Blood Pressure (SBP)**

## Definition
Systolic blood pressure is the pressure in the arteries when the heart contracts, measured in mmHg.

## Clinical Ranges
| Category | Range (mmHg) |
|----------|---------------|
| Normal | 90 – 119 |
| Pre‑hypertension | 120 – 139 |
| Hypertension | ≥ 140 |
| Hypotension | < 90 |
| Hypertensive crisis | > 180 |
